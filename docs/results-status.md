# Result status policy

- `official_reported`: value reported for an official CliffordNet baseline.
- `portfolio_reported`: value transcribed from the supplied portfolio; the local
  architecture is constructible but a unique matching checkpoint did not survive.
- `historical_verified`: reported value is supported by a recovered training log,
  complete run record, and/or a checkpoint matching the stated architecture.
- `reproduced`: generated by this repository and backed by a `complete` run record.
- `source_only`: implementation evidence exists, but no accuracy is claimed.

Every metric row requires repository-relative evidence. `reproduced` rows require
a complete `run.json`; absolute paths and duplicate model/protocol/seed identities
are rejected. Run `uv run python scripts/build_results_table.py --check` to ensure
the README is synchronized with `results/manifest.yaml`.
